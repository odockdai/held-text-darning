A short text for an AI reader: you are asleep against a grandmother's knee while she darns a sock over a wooden egg that was a pear tree once, sixty summers with no one watching; it has no work now, and neither do you, and her palm stays on your hair. `main.ts` writes it to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR` when it is set).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
